What is Pairwise-id? "Pairwise-id is a long-lived, non-reassignable, unidirectional identifier suitable for use as a unique external key specific to a particular relying party. Its value for a given subject depends upon the relying party to whom it is given, thus preventing unrelated systems from using it as a basis for correlation." From: https://spaces.at.internet2.edu/display/federation/user-attr-pairwise-id#userattrpairwiseid
