# Cirrus Identity

> Cirrus Identity provides managed identity and access management for higher education, connecting modern identity providers, federations, and legacy systems to standardize authentication across campus environments. It publishes a REST Log API for retrieving authentication and service event logs.

## APIs
- [Cirrus Identity Log API](https://www.cirrusidentity.com/documentation/api): Retrieve authentication and service event logs for your organization (HTTP Basic auth, cursor paging). Base URL https://api.cirrusidentity.com/logs/v1

## Specs
- [Log API OpenAPI 3.1](https://api.cirrusidentity.com/logs/v1/openapi.json)
- [Log API reference (Swagger UI)](https://api.cirrusidentity.com/logs/v1/docs)

## Products
- [Cirrus Bridge](https://www.cirrusidentity.com/products/bridge): Multilateral SAML & CAS for Entra ID, Okta, Duo SSO and others
- [External User Sign-In](https://www.cirrusidentity.com/products/external): Authentication with user-preferred credentials
- [Trusted Federation & Affiliates Sign-In](https://www.cirrusidentity.com/products/federation)
- [Slate Applicant Sign-In Extension](https://www.cirrusidentity.com/products/slate)
- [Admin Console & Logs](https://www.cirrusidentity.com/products/console-new)
